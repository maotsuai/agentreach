## 实现

- 单项目 schema-1 权威 envelope 保存 policy、私有 HMAC key、pending、approval、operation、有序事件和 checksum。审批消费与 intent 同次单文件原子替换，file sync/rename/directory sync 后才允许派发。读取严格、限长、检查实际 fd 身份、链接、权限与所有权；stale lock 不抢占。
- 显式 operator `policy init/set/inspect/approve/revoke`；Guest 默认 allow、Host 默认 deny。只读操作不初始化，缺失 policy 拒绝副作用。每次 policy 修改使旧计划失效。
- CLI/Claude exec、Codex process start/stdin、所有 managed write/mkdir/remove/rename/copy/native patch 均有 mandatory intent/result；Guest 完整参数仅保存私有 key HMAC。`REACH_NO_AUDIT` 不能关闭。多文件 patch 记录各 primitive，不承诺整体文件事务。
- 一次审批、默认 5 分钟、最大 15 分钟；Darwin CLOCK_MONOTONIC_RAW/boot-session UUID、Linux CLOCK_BOOTTIME/boot ID。跨进程、相同 boot 可用；boot 变化、不可用时钟、观察到的 tick/墙钟高水位倒退拒绝。墙钟不决定期限，不声称能检测每次微小调整。
- 固定 MCP 只有 plan/execute/status。Claude 精确 bridge callback 和 Codex 精确 argv/cwd/env/binding callback 都直接进入 typed handler，不执行 Host shell；operator 入口不暴露。Codex 保持 `include_local=false`。
- `open_url` 执行器只接受同绑定、健康、generation 匹配的 loopback exposure；成功派发仅由测试注入 registry/executor 验证，生产无 P4 来源时 `exposure_unavailable`。port/service/runtime driver `unsupported`，任意 Host shell/未知能力固定拒绝。

## 真实接缝问题与修正

预审最小 MCP 实验只证明本地 stdio 接缝，未证明与 `include_local=false` 远程执行环境共存。实施阶段保留所有失败记录，没有以直接 RPC 成功替代真实 harness：

1. Claude 2.1.220 通过 shell-prefix 启动 MCP，原 hook-only 规则拒绝。隔离 prefix 只记录 dummy 场景的实际 argv 后，新增精确生成命令到 typed handler 的窄 callback。原始/修正记录见 `bridge-claude*`；普通 Shell、非精确 callback 仍不进入 Host。
2. 实际 MCP call 带标准 `_meta`。只接受其不参与授权的传输 metadata，能力 arguments 继续严格未知字段拒绝。
3. 按 [官方配置参考](https://learn.chatgpt.com/docs/config-file/config-reference) 并核对固定 [0.148.0 源码](https://github.com/openai/codex/blob/rust-v0.148.0/codex-rs/codex-mcp/src/runtime.rs)，local stdio MCP 需要 local environment，不能为它开启通用 Host executor。固定 server 改经 reach executor 的精确 typed callback，仍使用 stdio、无新 broker/socket、无任意 Host argv。
4. Shell sentinel filter 为退出码扣留尾字节，会使 MCP initialize 的 JSON 行不完整。固定 MCP process pump 改为即时透传并使用 handler 完成状态；增加完整 RPC pump 回归，普通 Shell 退出码路径保持。
5. Codex 的独立 harness tool approval 与 reach operator approval 不同。仅固定三工具的 transport-level 模式为 approve，实际能力仍由 reach policy 独占审批；未放开其他 Host 工具。mock 修正 stdin EOF、异步发现、Claude content 数组和 Codex `Wall time/Output` 包装解析，保留首个失败，不降低真实 tool_result 标准。`codex-local-environment-diagnostic` 是隔离对照实验，不计 managed 验收。
